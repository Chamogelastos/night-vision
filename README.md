# NightVision
Veryyyy simple plugin to allow your users to use the command `/nv` and get night vision.

### Commands

| Command  | What it does                                | Aliases               |
|----------|---------------------------------------------|-----------------------|
| `/gamma` | Give the player night vision (Players only) | `/nv`, `/nightvision` |
